# First-release customer beta boundary

**Status:** accepted

Booking Consultation is the only live paid customer service in the first
release. Draft Studio and Cheque-bounce Notice are exposed only as Customer
Beta questionnaires so real users can provide product input without creating
payment, artifact, advocate-work, notice-issuance or legal-service entitlement;
the beta restriction is persisted on every new order and enforced again at
commercial workflow seams because a disclaimer alone would not provide a
reliable release boundary.
