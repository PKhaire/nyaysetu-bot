## Outcome

Choose `APPROVED`, `CHANGES_REQUIRED` or `REJECTED`. Record reviewer identity
and authority internally, authenticated decision/time, conditions and source
uncertainties. Changes create a new immutable candidate.

The release owner then verifies deployed hashes equal approved hashes,
Razorpay mode is intended, storage/deletion evidence passed, and activation is
global for all eligible users. Any mismatch blocks activation.
